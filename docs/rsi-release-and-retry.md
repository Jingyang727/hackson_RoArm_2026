旧时序实际上是：抓放与录像结束 → 分析 → 回位 → 下一轮观察 → 新录像。附件没有显示 T100 混进下一轮抓放录像。

## 高处投放

- 默认 `release_clearance_mm=100`，含义为**球底高出口沿100mm**，不是机器人 Z=100。
- 新投放高度学习域为80–160mm。它只用于漏斗投放，不限制坐标验证页的可选 XYZ。
- 开爪前用新鲜反馈核对**固件指尖高出口沿至少60mm**。不足时不发送释放指令，记录真实短差并为下一轮选择更高投放参数，重新检查完整 IK。
- 实测45.4mm口沿高度作为下限，避免黑色内沿深度偏低时把整个投放点压低。真实中心、姿态偏移和口沿高度分别保存。
- 旧策略里的18mm不会因改默认值而继续生效：prepare 会保存 `*.before-high-release-<id>.json` 备份，将过低投放高度迁移到100mm，递增策略版本，保留抓取 XY、历史记录和原标定。

这是针对已报告低位碰撞的额外间隙；固件 XYZ 仍是名义指尖，不能当成精确的整只夹爪三维外壳。现场需先核对高处投放预览及夹爪整体位置。

## 无效试验回滚后继续

当一次高度试验被判无效，而本轮又明确显示另一项 XY 偏差：先撤销失败高度参数，再从恢复的基线上生成一项新的平面试验，检查相机投影方向和完整路径后保存并继续剩余轮次。

记录明确区分 `rollback_parameters` 与 `trial_parameters`。这一步同时撤销旧试验、开始新试验；下一轮不会伪称它是单参数前后对照。曾被否定的完整策略仍会记忆，真实执行方向矛盾、未知结果和不可执行路径不会通过放宽检查来重试。

关闭“加力度”式自动学习。当前是夹爪角度接口，视觉模型不应建议增大力、扭矩或加紧闭合。抓空有明确方向时修正 XY/高度；没有方向时不会擅自降低高度。只有画面确认抓起后滑落，才按该类别降低运输速度。旧 `grip_tighten` 字段保留用于兼容历史记录，不会再增加 squeeze。

## 场景检查不要求夹爪出镜

官方初始姿态可以让夹爪位于画面外。视觉模型分别报告 `ball_visible`、`funnel_visible`、`gripper_state`（`empty` / `holding_ball` / `unknown`），程序据此计算ready：球与大开口可见，且没有明确观察到夹爪持球，即可开始。

夹爪不可见、遮挡或看不清内容时记unknown；它不代表已确认空爪，也不单独否决场景。旧版要求“看见空爪”的提示已移除，网页与OpenCode场景任务使用同一标准。缺少目标、目标误识别、开口被挡或明确观察到持球仍会阻止抓放。机械臂连接、六关节反馈和路径检查继续独立执行。

## 固定的录像与回位顺序

每一轮，包括成功轮：

```text
新鲜观察与规划
→ 启动本轮20秒录像并取得该请求的实际开始时间
→ 抓放动作与录像收尾
→ 官方回位并确认完成
→ 分析已保存的视频、更新经验
→ 成功则结束；有新试验且还有轮次则重新观察
```

动作耗时、录像时长、回位和分析分别计时。执行收据保存录像开始/最后帧的 monotonic 时间，恢复收据保存恢复开始时间。回位后的额外观察单独保存，20秒抓放录像的计时保持不变。

分析失败时会使用本轮已经确认的回位结果，不再重复 T100；新一轮的独立规划故障仍独立处理。停止按钮继续阻止后续动作及回位。

投放成功会自动结束任务，页面显示绿色“抓取并投放成功，自动任务已结束”，同时说明已回位、策略已保存。次数用完和抓起后滑落不显示成功。

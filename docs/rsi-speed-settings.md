# 网页配置抓放速度

打开 `/experiments`，展开“抓放速度”。页面显示当前标定对应策略的实际速度，包含以前RSI保存的调整；不会在更新代码时把本地策略替换成默认值。

- **转移／抬升速度系数**：高处接近黄球、抬升、运输等阶段的 `travel_speed`。
- **下探／靠近速度系数**：靠近球的竖直姿态调整、下探和靠近漏斗投放点的 `approach_speed`。

两项可设为0.05～1.0。新策略的默认值仍为0.65和0.30；点击“填入快速”会填入1.00和0.50，也可以自行输入。数值是T104控制器速度系数，不是毫米/秒，不能按比例承诺整轮耗时。1.0是本项目当前支持的配置上限。

点击“保存速度”，设置会作为这套标定的策略参数保存在本机，下一轮观察与规划时使用，重启后保留。已有位置补偿、夹爪参数和历史成功策略均保留；旧预览失效，需要重新规划。保存本身不连接设备、不切扭矩、不复位、不调用模型、不发送运动。任务执行或观察期间不可保存。

修改后未保存时不能开始任务，可点“重新载入”取消修改。若编辑期间策略或标定更新，先重新载入再编辑，避免覆盖旧值。RSI仍可以根据实际滑落等结果调整速度，页面随后显示策略的新值。

`/api/bench/rsi/state` 新增 `speed_settings_version=1` 和 `speed_settings`（两个速度、`policy_version`、`calibration_fingerprint`）。`POST /api/bench/rsi/speed` 提交这四项，校验版本后保存。每次改动记录在策略的 `baseline_resets` 中，标记 `kind=user_speed_configuration`，包含前后参数、版本及源试次；已有策略先备份，下一轮核对学习链时会计入这次用户设置。默认值读取和相同值保存不创建策略文件。

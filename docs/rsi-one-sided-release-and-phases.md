本轮依据用户提供的 `archive (4).zip`，试次 `78c7c889dceb4356ad31497a7df699af`，原代码 `1fb707b`。原始归档未改写，离线重放不发送运动，也没有调用公司的模型 API。

## 归档实际说明了什么

9.612秒抬升完成帧中，黄球在棋盘上、夹爪为空；11.614秒运输完成帧中，球仍在桌面。这份包支持本轮没有完成持球运输，不能拿它证明另一次“抓起后投偏”被误判。是否曾在两个采样帧之间短暂夹起，需要看相应连续录像，不能靠编码器到位推断。

旧接口实际给模型的是原始帧 `0,94,95,144,210,300`：94和95仅差64ms，运输帧174却被遗漏；释放帧210在开爪完成之后，没有开爪过程中的图。对应的时序回归夹具是 `tests/fixtures/reported_release_timing.json`，不含凭据、视频或本机路径。

旧计划投放XYZ为 `[262.794,278.055,24.283]`mm。运输后反馈为 `[267.224,266.406,28.027]`mm，竖直投放段保持实测XY，因此开爪前反馈为 `[266.507,265.690,12.539]`mm，XY与原计划相差约 `[3.713,-12.365]`mm。这是执行跟踪偏差，不能当作视觉方向映射的证明。

本轮实测指尖高于口沿约88.97mm，已通过高处开爪检查。该检查和抬升后平移、竖直下探路径继续保留。

## 固件端点与单边开爪

用户指定：端点向**物理左侧，即未镜像相机画面右侧**偏置，距离按“漏斗半径的一半”取 `76 / 2 / 2 = 19mm`。

之前的 `finger_offset_mm=19` 沿机械臂俯仰径向计算，不能等同于上述水平开爪偏置。本版：

- 抓球端点、姿态和已有抓取学习参数保持原算法。
- 投放XY改为漏斗中心上空、向原始相机画面右侧偏19mm。程序在实际投放高度用本轮标定的相机投影计算机器人XY方向，不固定翻转某个机器人坐标轴。
- 此偏置**替换**旧投放径向XY偏移，保留原俯仰相关高度和口沿间隙；之后才叠加新参考下的学习残差 `release_xy_mm`。它是当前装置的经验投放参考，不是完整的夹爪运动学标定，也不代表程序实测到了夹持中的球心。
- 第一次 prepare 自动备份旧策略为 `*.before-release-reference-<id>.json`，只将旧参考的 `release_xy_mm` 清零，记录 `baseline_resets`，增加策略版本，设置 `release_reference_version=2`。原始 reviews 和抓取参数保留。旧 `successful_policy` 保存在 `successful_policy_before_release_reference`，新投放参考需要重新验证。
- 新旧投放参考不作为单项学习效果对照；历史标定文件和历史试次不改写。

用本包的相机和布局离线计算，新端点为 `[269.375,287.828,24.283]`mm，抓取端点变化为零。相对于同高度漏斗中心，偏置XY约 `[-0.639,18.989]`mm，投影为画面向右约34.93px、上下变化为零。这个检查只验证方向计算和候选路径，不证明实物投放成功。

## 时序选帧与结果协议

完整RGB-D仍录20秒；一个模型请求仍最多6张图，每张含边框长边不超过768px。新增真实候选帧：开爪前、开爪窗口20%/50%/80%、开爪后0.5/1.5秒。没有执行开爪就不生成这些阶段标签。

模型选帧先覆盖闭爪、抬升、开爪前持球、开爪过程、末帧，再补动作前。多余位置用时间距离填充，不再优先塞入邻近闭爪重复帧。对本包重新抽取后是 `0,95,144,194,202,300`，分别为0、6.341、9.612、12.949、13.483、20.023秒。前轮对照和回位补充图仍共用6张预算；预算不足的阶段必须记unknown。

新增必填视觉字段 `phases`：

```json
{
  "pickup": {"result":"held|missed|unknown", "frames":[144], "note":"简短画面依据"},
  "transport": {"result":"held|dropped|unknown", "frames":[194], "note":"简短画面依据"},
  "release": {"result":"entered|missed|bounced_out|unknown", "frames":[202,300], "note":"简短画面依据"}
}
```

上面是字段说明，不是该归档的实际结论。`frames`必须引用本次实际发送的CURRENT原始帧编号；不能引用只存在于原视频、前轮或规划中的帧。未知阶段用unknown和空数组。

抓起/运输已确认持球、释放明确投偏时，程序归为 `placement_missed`；若模型仍填 `grasp_missed`，保留 `reported_outcome`，清除跨阶段的方向建议，不把抓球修正用于投放。持球但释放被遮挡时记unknown。最终球在桌面不能单独证明从未抓起。

前端实时结果和学习记录显示三个阶段、证据帧及说明；请求、原图、模型压缩图、逐阶段判断继续随本轮归档保存，为以后Langfuse同步保留依据。历史旧格式仍可读取；新的直接API分析缺少阶段字段或引用未提供的帧时不会应用判断。

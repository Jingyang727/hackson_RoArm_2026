## 这次补上的闭环

以前 Grok 收到当前录像和近期文字摘要；重复报告同一方向时，程序会累计小偏移，但没有让模型直接对照前后对应阶段的画面。数学投影一致也不能证明实物按预期移动。

现在已有学习循环承担有状态 RSI Agent 的职责：组织本轮与前轮的实帧、实际使用参数、预期变化和固件反馈；调用 Grok 做定性比较；程序计算数值试验并记录效果。继续直接调用公司 API，不增加 OpenCode 代理、模型网关或第二个机械臂控制器。

Grok 在原有结果、方向、幅度、建议与依据之外，返回：

```json
{
  "comparison": {
    "reference_plan_id": "前轮试次ID",
    "effect": "improved|worsened|overshot|unchanged|unknown|not_comparable",
    "movement": "as_expected|opposite|no_visible_motion|unknown",
    "note": "对照两轮画面说明效果的中文依据"
  }
}
```

无可比前轮时明确使用 `reference_plan_id=null`、`effect=not_compared`、`movement=unknown`。提供了有效图像对照时，模型必须引用正确试次并回答效果；遗漏或引用别的试次不会被当作已完成比较。

只有相同标定、相近目标位置、相近俯仰、前后对应动作、单项参数变化，且当前实际使用的参数确实来自前轮决策时，才建立比较。不同位置、不同动作阶段、重复使用同一段录像、缺图或旧参数关系不成立，均明确说明无法直接比较。这里的筛选只用于判断历史证据是否可比，不限制用户 XYZ 移动范围。

## 方向与步长

所有模型输入图都标出原始相机的 LEFT／RIGHT／UP／DOWN，明确不镜像。前轮标 PREVIOUS、本轮标 CURRENT。计划修正箭头只表示方向，并注明不是实测移动。Grok 按画面报告夹爪偏在哪边；程序通过既有标定换算反向修正，不额外翻转机械臂坐标轴。

数值是试验步长，绝不是 Grok 测量的绝对误差：

| 证据 | 下一轮行为 |
| --- | --- |
| 首次观察到明显偏差 | 中等 8mm、较大 12mm；较小 4mm |
| 实帧显示偏差缩小 | 缩至 2–4mm 收敛 |
| 已越过目标 | 按新观察方向修正，上一轮步长减半 |
| 实帧确认向预期方向移动但仍未明显改善 | 增大 4mm，单次最多 16mm |
| 旧版 2–3mm 试探看不出变化 | 扩大到至少 8mm 的可见试探，不据此断言方向错误 |
| 前后对照显示反向或越修越远 | 撤销上一轮该项参数，回到官方姿态后停止重复同向叠加 |
| 足够大的试探仍没有可见移动 | 撤销该次试验、回位并保留命令／反馈／视频证据，不把命令当作实际移动 |

只重复“没夹住／偏右”或粗略幅度标签，不再被自动当成需要加码的证据。无法比较时仍可按当前可见偏差做独立试验，明确记录改善尚未确认。已经被对照否定的策略摘要会保留；同一标定、相近目标位置与俯仰不会忘记并直接重放同一策略。

没有新增工作区、25mm 高度或附近 10mm 选点限制。上述步长与已有补偿搜索域只约束 RSI 如何试参数；官方关节、真实 IK 和原执行链继续负责实际路径检查。

## 画面和反馈

导出关键帧会额外保留闭爪完成、即将提升前的 `close_review`，提升完成后的 `lift_review`，以及释放完成后的 `release_review`。不会把没有释放动作的 finish 帧标成投放。旧的动作开始帧与新的完成帧不混作同一阶段比较。

Grok 同时看到带角色标记的前轮与本轮实帧；对应接触阶段使用目标附近的局部放大图，其他当前关键帧保留完整场景。放大不翻转相机方向，裁剪范围与原图副本一起保留。UI 的“前后动作实帧与修正效果”显示这些对应动作的局部图、参数前后值、要求的 XY 补偿、标定预测像素变化，以及固件报告的 XY 补偿变化。

固件反馈会扣除目标位置及名义姿态变化的影响，再与本次参数试验比较；反馈不足时不虚构位移。该数值仍是固件指尖参考点的报告，不是图像测得的夹爪中心位移。视频判断和数学／编码器判断分开记录；任一项都不单独证明物理抓取成功。

前后实帧对照图可从历史记录打开。选中的原始 JPEG 副本、带方向轴的模型输入、公开回复、正确引用的比较结果、策略变化和被否定策略摘要，均保存在现有试次／任务备份中，继续保留 Langfuse 待同步记录。

云端验证使用模拟设备与模型，覆盖前后参数与实帧绑定、目标移动扣除、反向／无效反馈、改善后缩步、反向回滚不进入第三次盲试、成功参数保存、阶段帧选择与原图不镜像。公司 Grok 对真实画面的比较和机械臂的实际方向，需要在本机用本轮记录验收；不将离线投影自洽宣称为实物已校正。

# 相机或机械臂底座移动后的重新标定

打开 `/calibration`，顶部“读取当前棋盘”现在始终显示。可以先点“开启实时画面”，在还没有标定参考时看当前相机原图；再点“采集当前棋盘并重新标定”。不需要事先录制空棋盘视频或选择旧录像。

保持相机、底座和棋盘固定，让全部9×6、54个内角点可见，单格边长沿用已实测的24.0mm。按钮通过现有独立相机服务采集2秒当前RGB-D，检查至少3帧完整且稳定的角点，生成显示全部角点和P1–P4、V1的参考图。此步骤不连接或移动机械臂，不切换扭矩，也不依赖Grok。

检测成功后进度从0/5开始。按原流程支撑、释放六关节，用同一固定触点手动对准五点并记录；五点完成后恢复扭矩。实时画面叠加本次参考的五点位置；进入人工对准后不再逐帧重排角点，以免遮挡时标记跳动。

每次重新标定建立独立目录：

```text
~/.evoarm/rsi/calibrations/<setup_id>/revisions/<新版本ID>/session.json
```

原来的 `session.json`、参考图、原始采点和试次都保留。`active-session.json` 保存当前版本指针，重启后继续当前版本，无需修改 `EVOARM_SETUP_ID`。浏览器标定、坐标验证、RSI和起步CLI共同读取该指针；新会话指纹会隔离旧RSI补偿。

按钮表示设备已经移动并要开始新标定，因此先切换到新版本，再采集。相机断开、角点不全或检测失败时保留“待重新标定”，不会回退旧布局继续抓放。调整画面后重新点击即可。五点记录齐全并通过拟合前，现有规划检查不会使用旧平面。已有运动或自动任务执行期间不能切换标定版本；页面加载、预览和采集按钮都不会代发释放、复位或抓放。

本地更新时沿用原Gemini Python和独立相机服务，只重启普通用户8765网页服务。`/api/bench/status` 的 `bench_api_version=2` 表示已加载这次更新。先验收实时预览、角点检测和新进度，再进行人工五点采集。

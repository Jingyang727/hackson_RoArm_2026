# EvoArm · 机械臂XY标定和黄色球抓取闭环

状态：**P1坐标标定 + 抓取参数示教 + 分段轨迹预览已实现（无自动执行）**。
执行动作仍需用户真机验收抓取高度、夹爪扭矩和工具姿态；下一阶段接入逐段受控动作，不会绕过验收。

## 验收目标

在固定的1080p俯视相机和水平桌面下，黄色球可放在**经过4点拟合及1点独立验证的可达安全区域**内不同位置，通过视觉识别定位；机械臂使用实测夹爪中心、抓取Z和已示教放置位，完成：
抬升到安全高度 → 移动球上方 → 张开 → 下探 → 夹住 → 垂直抬起 → 高位分段转运 → 下降放置 → 张开 → 撤离。
到位反馈、目标检测与异常确认必须逐段验证。**“摄像头视野内任意位置”不代表物理可达。**

## 步骤A：四点标定 + 独立验证

打开 http://127.0.0.1:8765/calibration

1. 固定棋盘纸、机械臂底座和摄像头。棋盘有9×6内部角点，单格边长 **必须用尺实测**；页面暂显示24mm只是前次检测的参考，不能代替实测。
2. 开相机并冻结识别54角点；图片应是完整的1920×1080，选取四个分散、机械臂能安全对准的角点P1~P4，再选第五个不同角点V1做独立验证。
3. 在原有控制UI中用小角度微步进，**人工让两指中点或固定工具尖端**对准所选角点。末端可以高于纸面，但五个点必须采用同样的夹爪姿态和类似的Z高度：Pitch/Roll相差不超过5°、Z不超过15mm。
4. 对准后点击“记录所选角点的机械臂XYZ”。系统连续采样两次T=1051反馈并检查静止；重复五次。
5. 检查拟合RMS和最大误差，再查看**独立V1误差**。当前门槛：RMS≤6mm，训练点最大误差≤9mm，独立验证≤10mm。这只是阶段性工程门槛，不保证抓球夹爪实际误差小于球半径。
6. 页面提示二维XY标定验收通过后点击保存到本机 `~/.evoarm/robot_xy_calibration.json`。自动移动依然禁用。若误差不达标，检查角点选择、工具尖端是否一致，重新标定；**不要靠直接放宽误差解决**。

扭矩示教可选流程：人工托住大臂 → 在标定页选择释放全部关节扭矩（T=210,cmd=0）→ 人工摆到所需位置 → 托住并确认重新锁定（T=210,cmd=1）→ **检查实际姿态没有偏移** → 读取XYZ。这一步不能自动执行，且释放后控制台禁止微步进。也可完全不使用扭矩模式，仅使用常规微步进。

**注意：** 微雪T=1051返回`tit`为末端Pitch、`t`为腕部关节角度，不能混淆。标定记录会校验`tit/r`姿态稳定。棋盘到机器人XY映射仅在工具姿态保持一致的条件下近似有效。

## 步骤B：抓取/放置示教

打开 http://127.0.0.1:8765/pick

1. 先输入实测黄色球直径（mm）。将小球放在棋盘内部可到达的位置，确保画面仍能看到棋盘54个角点。点击识别黄色球。
2. 用控制台手动对准**真正的球体**而不是纸上的格点：夹爪两指的中心应该与球的中心对齐。让手/身体远离运动部件，缓慢试探合适的抓取高度，记录“抓取Z+Pitch/Roll”。
3. 在已确认能高于球和桌面障碍的同一工具姿态下，示教**高位安全Z**，必须高于抓取Z与放置Z至少45mm。
4. 在固定的指定放置点，人工示教 **放置XY + 放置Z**；此位置不需要从视觉检测获得，但必须实测可达且不会碰到桌面。
5. 先用单独夹爪控制检查张开方向，然后在不夹痛手/压坏物体的情况下试夹泡沫球，记录打开角度和实际闭合角度。`T=106` 只控制目标角度，并不代表夹持力已得到校准或球已夹牢。
6. 点击保存示教参数，再点击“生成抓取-放置轨迹预览”。程序将拒绝球心位于4个标定点凸多边形边界外/太接近边界，拒绝异常高度、距离、夹爪开合角度、无有效XY标定等条件。

目前保存路径：`~/.evoarm/pick_profile.json`。

## 实际动作前还必须通过

- **球心平面投影误差**：相机识别球表面颜色区域中心，球高于桌面，若相机有倾斜，直接使用平面单应可能产生视差偏移。要用至少3个不同球位测量和修正真实夹爪对准误差。
- **固定TCP / 末端姿态**：示教者所指的两指中点必须与标定时选用的点一致；姿态不同会产生位置误差。
- **运动可达性**：T=104为曲线插值的阻塞式XYZ控制，不能假设轨迹中任何位置都无碰撞。优先以小动作测试并核对T=1051真实反馈。不要使用不带插值的T=1041完成跨区域移动。
- **抓取/闭合与放置验证**：实际观察球是否被夹住、抬升后是否仍在夹爪中、放置后是否已松开。没有这些反馈不能宣称“自动抓取成功”。
- **软件错误锁定 ≠ 急停**：正在执行的固件动作可能继续运动，必须备好独立切断动力的手段。

## 当前接口

- `GET /calibration`：机器人XY标定向导。
- `POST /api/calibration/start`、`/capture`、`/save`：四点 + 一点独立验证。
- `POST /api/teach/torque`：可选T=210扭矩切换，仅显式启用。
- `GET /pick`：抓取参数示教与轨迹预览。
- `GET /api/pick/teach`：只读、稳定的真实T=1051工具XYZ/末端`tit`/Roll/夹爪角度。
- `POST /api/pick/profile`：校验并保存抓取/放置示教数据。
- `POST /api/pick/preview`：必须已保存XY标定和抓取资料，纯计算预览。**不会发送T=104，不会移动机械臂**。

真机标定结果返回后再启用后续执行控制，这不是省略步骤，而是保持工具空间和碰撞数据可验证。

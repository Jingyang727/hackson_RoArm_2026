# EvoArm 顶部俯视摄像头 · 第一阶段

## 目标

用固定在桌面上方的 USB 摄像头观察 **平整桌面**，确认后再做视觉标定和抓取定位。
本阶段只做预览、保存单张 PNG，不控制机械臂；无需 Jetson、MPS、OpenCV 或额外依赖。

## 安全与安装

1. **先断开机械臂运动电源再安装支架。** 因此前发生过机械臂碰撞显示器的事故，先移开显示器、检查固定螺丝、夹爪、线缆与可能的运动扫掠区域。
2. 相机安装在 **独立支架** 上，镜头大致竖直向下；不要把支架固定到会随机械臂运动的部件。
3. 从镜头到桌面先试 **70–90 cm**，按 USB 相机的真实视角调整，以容纳 40×40cm 左右的桌面实验区域。这个尺寸仅为第一轮定位目标，并非机械臂的安全工作空间。
4. 让相机拍到：整个目标放置区、四个标定点，以及机械臂夹爪进入目标区时的位置。尽量避免照明反光与电线遮挡。
5. 用胶带在桌面标出四个角点（可先做约 30×30cm 或 40×40cm 矩形）；每个点到其他点的距离需用尺测量。相机安装稳定后不要再改变镜头或支架位置。
6. 机械臂测试时，实验台上不得保留显示器、玻璃杯等物品，人员与机械臂的运动范围保持距离；硬件急停/断电手段必须可及。

## Mac 浏览器预览

```bash
git fetch origin
git switch feature/evoarm-overhead-camera
git pull --ff-only origin feature/evoarm-overhead-camera
source .venv/bin/activate
python -m uvicorn control_ui.main:app --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765/camera`，点击 **启动预览** 并允许浏览器摄像头权限。
如果检测不到外接摄像头，在 Mac 系统设置 -> 隐私与安全性 -> 摄像头 中允许 Chrome/Safari，检查 USB 数据线，关闭占用相机的其他应用。
在预览中确认画面方向、覆盖、清晰度后，保存一张 PNG 发给后续视觉算法验收。
**本页面不会向内网模型上传图像**，浏览器只在本地显示摄像头画面，下载图片保存在 Mac。

## 后续视觉坐标标定（第二阶段，不包含在此次 UI 更新）

- 第一版采用桌面固定平面标定：四个不共线的已测量标记点 + OpenCV `getPerspectiveTransform` / `findHomography`，将像素点转换到桌面平面坐标。
- 将桌面坐标与机械臂基座坐标建立独立变换，校准夹爪末端中心与桌面高度。
- 验收 5 个未参与标定的点，用尺测量误差；标定不合格时不得开启自动抓取。
- 平面 Homography **不能**单凭一张图恢复球在空中的真实三维位置。

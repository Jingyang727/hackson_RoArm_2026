## 如何加载

运行时仍读取各电脑`~/.evoarm/rsi/`的活动标定和对应指纹策略，`git pull`不会替换这些文件。[当前快照与迁移说明](../README.md)给出了验证、备份导入和运行服务核验命令。

原文件内的Mac绝对路径是来源信息；导入工具保留字节，只把清单允许的相对路径复制到当前用户目录。历史成功试次只作为仓库证据，不安装到同事的本机执行历史。
